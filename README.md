# Tensku Gamble Hud (Fabric, Minecraft Java 26.3)

Client-side mod. Press **Right Shift** (rebind in Controls) to open the hub.

Features: profit tracker card, Pay Confirm (/pay guard), big-payment animation + sound,
themed chat colour, 7 GUI themes. Title "TENSKU GAMBLE HUD", credit "by tensku".

## Build with GitHub
1. Create a repo, upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab -> "Build mod" -> wait for green.
3. Download the artifact `tensku-gamble-hud-jar` -> unzip -> put the .jar in `.minecraft/mods`
   together with Fabric API 26.3 (Fabric Loader 0.19.5+, Java 25).
